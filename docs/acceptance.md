# 验收清单

入口：

- 开发入口：`index.html`（双击可用，经典脚本加载）
- 单文件入口：`dist/ProtoTweak.html`（所有 CSS/JS 内联，双击可用）

建议测试素材：

- `test/fixtures/prototype.html`
- `test/fixtures/annotations.json`
- 也可以用 `index.html` 里的“载入示例”

浏览器：Chrome / Edge 现代版本。建议用 1440px 以上宽度。

---

## A. 编辑器基础能力

- [ ] **A1 选中**：单击标题/按钮/表格，出现蓝色高亮；空白处单击取消；Esc 取消。
- [ ] **A2 拖拽**：选中任意普通元素拖动，位置改变，布局占位不变；导出后位置保留；Ctrl+Z 可恢复。
- [ ] **A3 文本**：双击标题、正文、按钮文案进入编辑；Esc/回车/失焦提交；可撤销。
- [ ] **A4 下拉选项**：双击 `<select>` 弹出选项编辑；可增删改、调整顺序、设置默认；保存后原生下拉内容更新；可撤销。
- [ ] **A5 插入**：工具栏「+ 插入」有 7 类元素 + 表格；插入后自动选中；图片以 data URL 内嵌；表格可设置行列和表头。
- [ ] **A6 表格行列**：选中表格后 +行/-行/+列/-列；表头/表体结构正确；最后一行/列有保护；可撤销。
- [ ] **A7 列宽**：单击表格选中整表，拖任意 td 的右边框；当前列变化，其他列宽度不被重新分配；可撤销。
- [ ] **A8 行高**：拖任意 td 所在行的下边框，行高变化；内容多时不会把内容裁剪到不可见。
- [ ] **A9 整表拖拽**：单击表格任意位置选中整个 table；拖动表格整体移动；整表选中时 8 向缩放手柄外移，所有列/行边框手柄仍可拖动；Alt+单击单元格进入单元格态，8 向手柄隐藏。
- [ ] **A9.1 八向缩放**：选中普通元素/整表出现 8 个手柄；拖拽实时预览；松手只提交一条历史；图片按住 Shift 等比缩放。
- [ ] **A9.2 互斥**：表格整体拖拽、整表缩放、单元格行列调整同一时刻只发生一种。
- [ ] **A9.3 scale 兼容**：表格自身带 transform: scale 时，行列拖动增量按 scale 换算，视觉拖动距离与列宽变化一致。
- [ ] **A10 复制**：选中元素 Ctrl/Cmd+C，粘贴到同一文档，保留 class、内联样式和子结构。
- [ ] **A11 粘贴**：Ctrl/Cmd+V 分别粘贴图片、HTML、纯文本，均落在选中元素附近/单元格内；HTML 中的脚本被移除。
- [ ] **A12 样式面板**：修改 X/Y、宽高、文字、字体、颜色、背景、透明度、边框、圆角、阴影、四边间距，实时生效；可撤销。
- [ ] **A13 撤销/重做**：文本、拖拽、插入、删除、表格、样式、粘贴都能 Ctrl+Z / Ctrl+Y；撤销后批注仍能对准元素。
- [ ] **A14 预览**：切换预览后不能编辑；样式面板只读；批注点是否显示可在右侧「批注」页签配置。
- [ ] **A15 保存/导出**：Ctrl+S 保存干净 HTML；导出菜单有干净 HTML、评审版 HTML、批注 JSON、变更摘要、PDF；PDF 不包含编辑器 UI。
- [ ] **A16 空白取消**：点击页面空白取消选中、关闭样式面板内容、关闭高亮。

## B. 打点批注

- [ ] **B1 模式开关**：顶部「批注」开启后，点击元素只添加批注，不触发选中/拖拽/文本编辑/表格操作。
- [ ] **B2 打点**：点击元素生成带序号小点；小点锚定元素，滚动/缩放/拖拽后仍对准；同元素多条会错开。
- [ ] **B3 卡片**：点击批注点弹出卡片，显示正文、类型、状态、PRD 引用、选择器/文本快照、时间。
- [ ] **B4 编辑/删除/已解决**：卡片内可改正文、类型、PRD、状态；状态同步右侧列表和点颜色；可删除。
- [ ] **B5 持久化**：刷新页面后自动恢复草稿、批注和批注点。
- [ ] **B6 JSON**：导出批注 JSON 含 `selector/content/type/status/prdRef`；导入后可恢复；字段可被 AI 读取。
- [ ] **B7 跟随**：滚动 iframe、窗口缩放、拖拽元素、表格操作后，批注点重新定位。
- [ ] **B8 孤立**：删除被批注元素后，右侧列表和点标红“孤立”；可删除或「重新锚定」到新元素；撤销删除后自动恢复。
- [ ] **B9 隔离**：批注层不写入用户 DOM；干净导出不含批注 UI；评审版使用 Shadow DOM 查看器。
- [ ] **B10 两种导出**：干净 HTML 无批注；评审版 HTML 含批注点且可点击查看。
- [ ] **B11 右侧列表**：显示全部批注的序号、类型、状态、摘要；筛选全部/未解决/已解决/孤立；点击定位并打开卡片。

## C. 工作流支撑

- [ ] **C1 版本基线**：每次修改后自动快照；“保存版本基线”会保存并下载干净 HTML；版本历史可恢复/下载/删除。
- [ ] **C2 变更摘要**：导出 Markdown，包含批注清单、未解决项、孤立项、修改清单和选择器。
- [ ] **C3 单文件**：`dist/ProtoTweak.html` 双击可打开；无 `<script src>`、无外部样式表、无 CDN。

## 快速测试步骤

1. 双击 `dist/ProtoTweak.html`。
2. 导入 `test/fixtures/prototype.html`。
3. 单击标题 → 拖拽 → 双击按钮文案修改 → 双击下拉框改选项。
4. 选中表格 → 插入行/列 → 拖列宽/行高 → 拖动整表。
5. 选中标题 → Ctrl+C / Ctrl+V；粘贴一段 HTML 和一张截图。
6. 修改右侧样式，Ctrl+Z / Ctrl+Y。
7. 开启批注 → 在表格单元格、按钮、标题上各加一条 → 改状态/类型/PRD。
8. 滚动页面、缩放窗口、拖拽元素，确认点跟随。
9. 删除一个被批注元素，确认孤立；撤销，确认恢复；或重新锚定。
10. 刷新页面，确认草稿和批注恢复。
11. 导出批注 JSON，导入 `test/fixtures/annotations.json`，确认恢复。
12. 导出干净 HTML，打开确认无编辑器 UI；导出评审版，确认点可点击。
13. 导出变更摘要，确认包含批注和修改。
14. 打开版本历史，恢复一个旧版本。

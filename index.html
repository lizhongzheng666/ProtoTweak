操作指南与快捷键

默认状态下原型保持真实交互。按住 Ctrl（Mac 为 Cmd）再点击，才进入 ProtoTweak 的选中与编辑模式。

开始编辑

  1. 导入：拖入 HTML / 文件夹，或点击 Tab 栏 + 选择文件、粘贴代码。
  2. 选中：按住 Ctrl/Cmd，画布出现十字准星；点击元素出现实线蓝框与右侧面板。
  3. 编辑：右侧面板修改文字、样式、尺寸；表单和下拉框在对应分组中编辑。
  4. 拖动：选中元素后直接拖动；8 个手柄缩放。表格先选中整表，再拖动或整体缩放。
  5. 交付：批注后导出干净 HTML、评审版、JSON 或 Markdown。

选中与表格

Ctrl/Cmd + 单击选中元素；表格先选中整表
整表选中后再单击单元格进入具体单元格
双击单元格编辑单元格文字
Esc（单元格）返回整表；再按取消选中
Alt + 单击表格直接选中整表
单击原型其他位置取消当前选中与编辑
右侧“选择整表”从单元格回到整表状态

快捷键

Ctrl/Cmd + Z撤销
Ctrl/Cmd + Y重做
Ctrl/Cmd + C / V / X复制 / 粘贴 / 剪切选中元素
Ctrl/Cmd + D快速复制选中元素
Ctrl/Cmd + S保存干净 HTML
Ctrl/Cmd + Shift + S另存为
方向键 / Shift + 方向键微调 1px / 10px
Delete / Backspace删除选中元素（二次确认）
Esc关闭弹窗 / 退出批注 / 取消选中
右键复制、删除、编辑文字、添加批注

页面、Tab 与批注

  • 顶部「内部页面」控制当前 HTML 原型内部页面，与文件 Tab 完全独立。
  • 文件 Tab 切换会清空当前选中并加载该文件的批注数据。
  • 批注模式下点击元素只创建批注点；右侧切到「批注」查看列表。
  • 批注支持标记已解决、JSON 导入导出；批注数据保存在 localStorage。

请只加载可信 HTML。原型脚本在沙箱 iframe 中运行；默认保持原型原生交互，按住 Ctrl/Cmd 才进入选中模式。
